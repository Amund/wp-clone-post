# wp-clone-post

**wp-clone-post** is a WordPress plugin that add a "clone" link to posts, pages and custom post types.

## Installation

1. Add repository to your `composer.json` file:
```json
{
    "repositories": [
        {
            "type": "vcs",
            "url": "https://github.com/Amund/wp-clone-post.git"
        }
    ]
}
```

2. Run the following command to install the plugin:
```sh
composer require amund/wp-clone-post
```
